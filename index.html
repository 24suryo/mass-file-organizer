Pertanyaan Sering Diajukan (FAQ)

Q: Apakah file saya aman diunggah ke server?

A: Sangat aman. Aplikasi ini bekerja 100% secara lokal di browser Anda (Client-side JavaScript). File Anda tidak pernah dikirim ke server luar manapun.

Q: Bagaimana cara kerja Auto-Organize Rules?

A: Sistem membaca ekstensi file (seperti .pdf, .jpg) atau kata kunci pada nama file, lalu mengelompokkannya secara otomatis ke dalam folder tujuan virtual sebelum diunduh sebagai file ZIP.

Q: Apa bedanya versi Free dan versi Pro?

A: Versi Free dibatasi maksimal 10 file per proses. Versi Pro membuka batasan jumlah file (unlimited) dan mendukung kustomisasi aturan lanjutan.
